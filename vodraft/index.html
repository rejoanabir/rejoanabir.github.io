Native Built-in

Want zero setup? Skip the API key and use Android's native SpeechRecognizer with live streaming partial words inside the floating pill and instant offline rule-based cleanup.

Auto-Fallback: Even if you're offline or remove your key, Vodraft smoothly falls back to the offline rule-based cleaner.

Hardware-Backed Encryption & FLAG_SECURE

Your API keys and JWT tokens are encrypted on-device with Android Keystore (AES-256-GCM). Sensitive screens block screenshots via FLAG_SECURE, and signing out wipes cached local secrets from disk.

3-Tier Universal Text Insertion

First attempts direct ACTION_SET_TEXT (ignoring placeholder hints with smart spacing), falls back to Clipboard + ACTION_PASTE, and finally Clipboard + Toast so dictated text is never lost.
