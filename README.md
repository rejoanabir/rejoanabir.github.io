# Rejoan Abir — Personal Portfolio & Engineering Showcase

The official personal portfolio of **Rejoan Abir** (`ANDROID ENGINEER • MOBILE UI/UX ARCHITECT • AI SYSTEMS DEVELOPER`), founder of **Veltus Studio**. Built with **HTML5, Tailwind CSS, GSAP 3 (GreenSock), Web Audio API, GitHub REST API, and HTML5 Canvas Particles**.

Live at: **[https://rejoanabir.github.io/](https://rejoanabir.github.io/)**

---

## 🚀 Key Functional Modules

1. **Brand & Identity**:
   - Engineered for **Rejoan Abir** with deep obsidian noir, electric cyan, and cyber violet styling.
   - Dual connection to both personal GitHub (`@rejoanabir`) and organization (`@veltus-studio`).

2. **3D Developer Desk Hero Scene**:
   - High-fidelity 3D developer character working at a tech desk with laptop, companion robot mascot, glowing code symbols (`{ }`, `</>`), and floating interactive tags.
   - Real-time 3D mouse parallax tilt physics.

3. **Dynamic Live GitHub API Integration**:
   - Live repository feed connected directly to `api.github.com/users/rejoanabir/repos`.
   - Real-time stars, forks, language badges, and commit activity with zero-latency cached fallback.

4. **"Get To Know Rejoan Abir" & 4 Animated Stat Counters**:
   - 3D waving avatar portrait card.
   - Animated count-up numbers: **15+** Projects, **4+** Years Engineering, **100%** Clean Architecture Pass, **10+** Core Tech Stack.

5. **Featured Showreel & Motion Player**:
   - 16:9 neon-framed cyberpunk studio showreel banner with fullscreen interactive audio visualizer modal.

6. **Interactive Contact Form**:
   - Real-time input validation, auto-draft saving via `localStorage`, synthetic audio chime feedback, and neon toast notification.

7. **Technologies & Skills Matrix**:
   - Interactive elevated cards with hover lift for Kotlin, Jetpack Compose, Android SDK, GitHub Actions, AI & LLMs, Coroutines, Clean Architecture, Material 3, Python, and Git.
